# 适配器实现契约 / Adapter Contract

供按本规格实现集成层的人使用。**本仓库不含参考实现。**

---

## 1. 统一签名

每个阶段一个适配器，**统一返回三元组**：

```
(下游契约, 校验报告, 人工介入请求列表)
```

| 位置 | 类型 | 约定 |
| --- | --- | --- |
| 1 | 下游契约实例 | 必须通过自身 `validate()` |
| 2 | 校验报告 | 含 errors / warnings，可序列化 |
| 3 | `List[dict]` | **恒为列表**；无断点即空列表 |

> ⚠️ 第三个返回值的类型**必须从头到尾一致**。
> 若某个适配器返回 `dict | None` 而其余返回列表，
> 调用方 `len()` 会报错，另一处 `list(result[2])` 会把 dict 拆成键名列表。
> 这种"半对"的类型最难排查。

## 2. 必需行为

| # | 行为 | 说明 |
| --- | --- | --- |
| 1 | 转换前先校验输入契约 | 不合格立即抛结构化断点，不要带着坏数据往下走 |
| 2 | 遵守[四级判定](criteria.md) | 逐列判定并留痕 |
| 3 | 不猜测语义 | 未声明的留 `TODO`，或抛 `ambiguous_semantics` |
| 4 | 不编造数值 | 源里没有的统计量一律留空并报 warning |
| 5 | 追加血缘 | 在下游契约的 `provenance` 末尾追加一步，`inputs` 写上游契约 id |
| 6 | 幂等 | 同输入重复执行产出逐字节相同；内容未变不重写文件 |
| 7 | 路径安全 | 本蓝本把路径字段限制为工作区相对路径（在模型校验器里挡，而不是靠调用方自觉） |
| 8 | 统一退出码 | 见 [interventions.md](interventions.md#4-退出码约定) |

## 3. 五个阶段的适配器职责

| 适配器 | 转换 | 关键行为 |
| --- | --- | --- |
| `sim_to_clean` | S1 → S2 | **全表转换**（漏表会导致下游指标丢失）；按四级判定给 WARN |
| `clean_to_analysis` | S2 → S3 | **技能门禁**：未实测验证（`verified=false`）的技能拒绝自动执行 |
| `analysis_to_figure` | S3 → S4 | 只产出契约不出图；统计量不足时抛结构化断点 |
| `render_to_figure` | S3 → S4 | 真正出图；本地兜底 / 上游原生技能 / 自动择优 |
| `figure_to_report` | S4 → S5 | 生成 Markdown；图注缺失写**显式占位符**，不编造 |

## 4. 技能门禁（最重要的一条纪律）

注册表中每个技能带 `verified` 与 `verified_how`：

| 字段 | 含义 |
| --- | --- |
| `verified` | **是否实测跑通过**。未通过则适配器拒绝自动执行 |
| `verified_how` | 实测证据（跑了什么命令、得到什么结果） |

> **没有证据不得置 `verified=true`。** 这个门禁是把"看起来能用"与"确实能用"分开的唯一手段。
> 实测能跑的比例通常很低（本例 601 个中仅 1 个）。本蓝本把这个数字**直接写在能力声明里** ——
> 使用者有权知道真实比例，而不是自己去撞。

## 5. 调用外部脚本时踩到的五个坑

本蓝本真的去调上游脚本时，逐条撞上来的。列出来**不是清单，是事故记录**：

| 撞上什么 | 现象 | 后来改成 |
| --- | --- | --- |
| 脚本路径不存在 | 解释器直接崩溃（Windows 上 `0xC0000005`），**stderr 全空** | 先 `isfile` 校验；路径用**双路查找**（镜像优先 → 注册表兜底），拿不到就抛断点 |
| 路径含空格 | 参数被切断 | 程序路径与参数分开处理；优先 **argv 列表**直传，不用 `shell=True` |
| 程序名被子串替换 | `str.replace("scripts/", …)` 会把 `Rscript.exe` 改坏 | **只处理"看起来是路径"的参数**，不要全局替换 |
| 子进程环境不继承 | "明明装了却报没有这个包" | 把子进程环境构造抽成**唯一实现**，所有调用方共用 |
| 依赖探测不真实 | 只读配置判断，未问运行时 | **真问运行时**，且用其**实际解析出的路径**去探测 |

> "能力具备" ≠ "这份输入喂得进去"。
> 自动择优必须同时满足：后端具备 + 执行器已装配 + **本契约确实可喂**。
> 只满足第一条就选高优先级通道，结果是**撞墙，不是自动**。
